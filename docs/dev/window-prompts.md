# 工作包启动说明

## 总控

按用户目标一次性分配一个可验收的完整工作包：角色标签、独立 worktree、codex/<工作包> 分支、完整基线 SHA、精确文件范围、验收和风险测试策略。可以把接口与跨模块实现放在同一个包，不为角色标签人为拆包。

先确认其他活跃任务没有使用相同工作区/修改文件；任务卡由总控发布到可信基线后开始。只对产品歧义、外部操作、新权限和范围扩大请求用户决定，不反复确认常规实施细节。

总控汇总 progress，各包独立 handoff。普通包不得改检查器/授权规则；规则升级需要单独的用户授权。创建任务/代理、提交、推送、合并、安装依赖仍遵循用户授权。

## 开发窗口提示模板

```text
工作包：<名称>；主责：<integration|core|retrieval|cleaning>。
worktree：<绝对路径>；分支：codex/<工作包>。
可信发布基线：<完整SHA>；任务卡：docs/dev/tasks/<工作包>.json。
目标及验收：<行为与规格编号>。
先读 AGENTS.md、parallel-plan.md 及相关规格；只修改任务卡授权文件。
同包接口/实现/测试一并完成；影响其他活跃包或破坏兼容性时先协调。
运行 python3 tools/collab_gate.py package --base <SHA> --task <任务卡路径>。
测试风险按任务卡执行，不能自行降级；不把模拟/定向结果称作真实/全量通过。
在任务卡指定的独立 handoff 更新进度和真实验证结果；不要与其他包共写总看板。
遇到范围冲突只暂停受影响部分；保留他人修改，不自动提交、合并或推送。
```

## 旧任务兼容

已经分派的旧卡继续使用原分支及 check --role 命令；不要仅修改候选卡就切换新模式。需要迁移时由总控重新分配新卡和可信基线，核对未提交改动归属后再切换。
