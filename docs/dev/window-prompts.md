# 可选的并行开发提示

普通单任务开发直接遵循根目录 `AGENTS.md`，无需使用本模板、任务卡或总控派发。

只有用户要求多人并行时，才给每个写入者说明：目标与验收、独立 worktree、可能重叠的文件、共享接口约定和测试要求。开始前检查其他写入者的未提交修改；重叠部分先协调，不整文件覆盖。

可选提示：

```text
目标：<可验证的结果>。
当前工作区：<独立路径>；请先检查 git status。
相关文件或协作边界：<仅列出需要协调的重叠区域>。
相关规格与验收：<章节/场景>。
实现后运行相关测试；高风险变更和阶段发布运行完整回归。
在 docs/dev/progress.md 记录完成内容、测试结果和未验证项。
保留其他窗口的未提交修改；有冲突先沟通。
```

旧任务卡若仍在执行，按其已发布约定使用既有 `package` 或 `check --role`；该要求不扩展到新的一般任务。
