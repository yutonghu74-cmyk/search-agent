## 缺陷与修复验收建议

1. **高优先级：作业层没有有限重试/退避。** `cleaning_dispatch.py` 的可重试 ServiceError 和普通异常都不持久化尝试次数，下次轮询再次执行。即使单次模型 HTTP 请求有限重试，作业层仍会不断重新请求。修复应持久保存 attempt/next_retry_at/终止状态，并测试预算耗尽、时间推进、重启继承预算及显式重试权限。
2. **高优先级：终止失败在重启后丢失。** `_failed` 是内存字典；新协调器只看到未完成批准，就返回 queued。修复应持久化失败状态并绑定 task/revision/generation；未经重新确认或获准重试，不应自动恢复执行。

两项目前都没有造成测试中错误发布，但会导致状态误导、重复执行或模型调用成本风险。本轮不把它们修成“通过”，失败用例作为下一轮修复依据。

## 本轮未验收

- 真实 VLM 对狗/猫、否定条件、遮挡、混合主体、图片文字注入的判定质量：应另建独立标注集，逐图记录期望标签、版本、实际输出和误判，不以 Mock 证明模型质量。原有两张狗图自测不构成这组验收。
- 运行中逐图进度/断点续跑、人工复核闭环、跨进程执行租约、生产媒体撤权/删除联测、公司内网链路、吞吐和费用预算。
- 新生产线路首页的完整交互验收；本轮没有把后端用例通过当作浏览器视觉验收。
