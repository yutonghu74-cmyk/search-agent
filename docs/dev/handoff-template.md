# 角色交接模板

- 角色 / 分支 / worktree：
- 任务切片 / 规格验收编号：
- 分派基线 SHA / 当前代码提交 SHA（尚未提交须注明）：
- 状态：READY_FOR_REVIEW / BLOCKED（只有 A 验收后可标 ACCEPTED）
- 完成范围与修改文件：
- 契约版本 / 是否提出变更（原因、示例、兼容性及影响方）：
- 实际测试命令、环境、时间、退出码与结果摘要：
- 角色门禁结果：
- 模拟与真实联测的区分：
- NOT_RUN 项与原因（内网/W3/恢复/性能等）：
- 剩余风险 / 所需决策 / 下一步：

检查器仅检查交接文件存在，不验证文字真实性。由 A 对照 diff、日志与验收测试审查。
