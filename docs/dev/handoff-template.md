# 工作包交接模板

- 工作包 / 主责 / 分支 / 独立 worktree：
- 任务卡 / 可信基线 SHA / 当前代码状态（未提交须注明）：
- 目标 / 规格验收编号 / 修改范围：
- 状态：IN_PROGRESS / BLOCKED / READY_FOR_REVIEW（审查后 ACCEPTED）
- 关键实现 / 接口兼容性 / 影响其他包：
- 风险与测试策略：full / targeted / docs，选择依据：
- 实际命令 / 测试数量 / 退出码 / 结果：
- 范围检查结果；定向不等于全量，模拟不等于真实：
- NOT_RUN / 风险 / 下一步：

## 开发明细

按时间追加关键里程碑和阻塞/恢复，不复制整段日志；活跃最长 30 分钟更新一次。
总控汇总 progress.md，各包不共写一个角色 handoff。旧任务仍可按原角色 handoff 交付。
检查器仅检查交接存在，不证明内容真实；由审查者核对代码与证据。
