# W3 登录对接约定

2026-10-20：用户确认公司内部使用 W3 登录系统，检索产品接入 W3。
当前仅确定身份提供方，协议、应用注册及真实接口尚未提供，状态为 NOT_CONNECTED。
不假设 W3 是 OIDC、OAuth、SAML 或特定厂商产品，不根据名称编写虚构接口。

## 预期登录流程

1. 用户打开检索产品，未认证时进入 W3 登录流程。
2. W3 完成身份认证；按照内部接入契约，由可信网关或业务后端验证返回的凭证。
3. 后端把已验证的稳定用户标识映射到内部 user_id，结合服务端组织映射取得 tenant_id。
4. 建立或使用内部规范允许的登录会话；前端查询当前用户，不自行指定可信身份。
5. 每次任务操作校验登录身份与任务权限；目录、素材、预览、下载分别校验资源权限。
6. 会话过期时要求重新认证，任务数据保留；退出登录时失效本产品会话。
   是否联动 W3 全局退出按其协议确定，不能未经确认退出其他内部应用。

W3 证明用户身份，不默认授予所有素材访问权。角色、组织字段是否由 W3 提供、
是否可直接用于授权，须经字段及权威来源确认；姓名/邮箱不作为不可变用户主键。
若 W3 不提供租户，采用服务端维护的组织映射，不能相信浏览器传入的 tenant_id。
没有有效映射的用户不得自动获得默认租户访问权。

按 v1.9，本期业务确认仅由需求发起人处理；项目访问权不赋予代确认权，
不开放转派或多人会签。W3 卡片和内部待办跳转同一确认事项，
重复点击或网络重试返回已处理结果，不重复推进；仅登录或待办已读不构成批准。

## 两种接入位置待内部契约选定

| 内部已有能力 | 接入方式 |
| --- | --- |
| 统一网关已完成 W3 认证 | 后端验证可信网关来源；网关删除外部伪造身份头并重新注入。后端禁止绕过网关的直接访问 |
| 产品需要直接对接 W3 | 增加 W3 认证适配层，按实际协议完成登录入口、回调或凭证验证及会话管理 |

应用身份与 Worker 服务身份分别管理；不把用户登录凭证传给 DSH、DJ 或写入模型上下文。
长期后台任务不以浏览器保持在线为前提，但继续调度前仍检查账号和资源权限；
账号停用或资源撤权应阻止新的受限操作。普通登出是否取消后台任务由产品策略明确，
不将登出自动等同于取消任务。

## 内网需提供的信息

- W3 接入指南或一个已有项目的脱敏认证示例；确认网关集成还是应用直连。
- 协议及测试环境入口，应用注册步骤、允许的回调/退出地址和部署域名。
- 凭证验证方式、稳定用户标识、组织/角色字段定义及脱敏成功/失败响应。
- 凭证/会话有效期、刷新、停用、撤销和退出语义。
- 测试账号申请方式、网络及证书要求、接口负责人。

应用密钥、真实票据、密码等由内网配置或密钥管理注入，不提交代码或文档。
接口未确定前不添加假定的认证地址，也不宣称填写配置即可启用 W3。

## 当前实现与上线门禁

当前 api.py 仍直接读取 X-Tenant-Id/X-User-Id，是本地开发模拟身份，
没有验证 W3 凭证。此次设计登记不会改变该行为，也不构成认证接入完成。
生产接线必须用实际验证过的认证结果生成 Actor；W3 未配置或验证失败不得
回退到模拟请求头。登录身份与 AuthorizationService 的资源授权分别测试。

接入验收至少覆盖：正常登录、无/过期/伪造凭证、回调与重复票据处理
（按实际协议）、稳定用户映射、跨用户任务隔离、账号停用、退出、
SSE 重连及媒体预览/下载的认证、W3 故障时不放行。
协议专属验证项在取得官方内部文档后冻结；这些测试目前均未执行。
