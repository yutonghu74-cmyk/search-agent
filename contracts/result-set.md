# 精确内容去重结果预览契约（开发切片）

`build_exact_result_set(approved_job, complete_result, target_count)` 处理已完整清洗的图片批次。它要求结果与已批准作业的绑定、候选及规则完整一致；只有全部硬规则 `pass` 的素材才进入精确内容哈希去重。相同内容摘要按候选 ID、素材版本的稳定顺序选一个代表；代表再按稳定顺序取目标内 `accepted`，余量列为 `reserve`。`fail`、`unknown` 和重复副本各自计数，均不计入 `accepted_count`。固定输入不足时为 `INPUT_SCOPE_COMPLETE`；自动补数按已确认策略进入等待或调度，不能误报检索耗尽。

累计合并对“新增对新增”和“新增对历史”统一按内容摘要去重并重算缺口。新结果快照为每个代表保留同内容 `candidate_ids` 和跨词、跨库、跨轮 `sources`；来源证据进入结果摘要和交付 manifest，但一个精确重复簇仍只贡献一个有效数量。旧 v1/v2 快照缺少融合证据时继续按原摘要读取，不补造来源。

当前生产去重策略只启用 SHA-256 精确内容去重：清洗执行器先复验授权图片字节摘要，只有摘要完全一致的合格候选才自动合并为一个有效素材，无需人工复核。稳定代表保留全部 `candidate_ids` 和 `retrieval_sources`，跨检索词、素材库及补数轮次仍只计一次；摘要不同的图片不因视觉或语义相似被自动合并。

pHash 近重复评估、重复簇人工裁决和质量代表图推荐暂不属于当前启用范围。历史开发快照中的相关字段仅作兼容读取，不在新清洗结果中生成，也不在当前界面提供复核入口；后续如重新启用必须单独完成策略、阈值与产品验收。

输出绑定清洗结果摘要、operation、generation 和 task_version，生成稳定结果集摘要。生产发布必须重新读取当前账本与授权并在业务事务内复核。
