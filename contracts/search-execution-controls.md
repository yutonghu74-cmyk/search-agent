# 检索执行并发、排队与预算

适用：LOCAL_EXACT、LOCAL_CLIP、PLATFORM、CLIP_COMBINED。不更改计划批准、查询/索引绑定、授权、版本/generation、候选确认或业务有效数量规则。

## 调度

同一服务实例默认2个首轮执行线程；按租户/用户标识轮转，同用户任务FIFO，每个任务每轮仅执行一页，长任务重新排到尾部。同一用户最多一个首轮任务执行。队列最多容纳128个执行中/待执行项，同一用户默认最多16项，避免单用户填满入口；满时分别返回可重试503 `SEARCH_QUEUE_FULL` / `SEARCH_USER_QUEUE_FULL`。重复排队不增加条目，执行中的重复通知至多追加一次跟进。

已批准计划/分页和组合CLIP作业仍是持久恢复依据。重启生产者先交错不同用户，再按容量补入，不将内存队列当作持久任务账本。关闭后不接收新项；完成在途请求后退出，未完成批准记录仍可恢复。可重试依赖故障有界重试并退避，让出其他用户；忙碌等待不消耗检索额度。

手动tick和补数也经过同服务执行槽和每用户互斥。锁覆盖读取、外部请求和提交，避免网络已返回但提交未完成时重复派发同页。并发冲突返回可重试503 `SEARCH_BUSY`，不表示该页失败或已执行。现有批准和回传版本校验继续执行。首轮/补数outbox中的单条故障或用户配额满保留该事件待重试，不阻断其他用户的后续事件。

首轮队列公平性不等于整个平台所有模型/媒体作业的统一公平调度。补数保留现有持久outbox派发，受相同执行槽与额度约束；本轮没有实现跨进程的全局并发租约或多实例公平队列。

## 每任务预算

服务默认每个`租户/用户/项目/任务/revision/generation`最多预留128次检索调用、1000个原始命中名额。所有分支/库、首轮/手动/补数合并计算。task_version推进或同代次重新批准不重置；新正式revision/generation分别计量。

调用前在SQLite短事务中原子预留1次调用与本页批准的batch_size；余额不足拒绝整页，不擅改已批准请求大小。并行连接或进程不能超额预留。已发出、失败或中断的调用不自动退额：响应不确定时无法证明依赖端没有执行。完成页重放不发请求、不新增额度。

字段`calls_reserved`/`hit_slots_reserved`为保守预留，**不是供应商计费次数、已返回条数、候选素材数或有效去重数量**。一个原始向量命中可能映射多个素材；原有候选清单/分页和媒体资源限制仍独立有效。启用前历史调用没有可靠记录，`accounting=reservations_since_enablement`明确不倒推历史消费。

首次调用冻结当前scope上限；提高服务配置不扩大已经开始的scope。降低配置可收紧后续调用，不退款、不抹去已有消费。耗尽持久标记stop_reason，HTTP409 `SEARCH_BUDGET_EXHAUSTED`；首轮不再自动重试，补数落`EXECUTION_LIMIT_REACHED`并结束派发，不伪造空页、不产生清洗intake。已有结果保留可读，工作区显示预算停止，不将其当作检索成功、目标满足或素材合格。扩大既有任务预算需要另行实现明确确认流程，本轮不提供静默充值接口。

预算停止通知与停止记录同事务写入既有任务事件流，只对匹配租户/用户/revision/generation的流发布；重复拒绝不重复发事件。新表`retrieval_execution_budgets`已纳入存储白名单、任务/Chat级联清理及迁移源指纹。

已有任务确认的补数轮数/VLM限制继续生效。本轮的调用额度是检索网关执行预算，不是对话、扩词、清洗模型及供应商费用的统一配额。

## 配置与可见性

本地CLI：`--search-workers 2 --search-max-pending 128 --search-max-pending-per-user 16 --search-max-calls 128 --search-max-hit-slots 1000`。

平台私有配置可增加：

```json
{"search_limits":{"workers":2,"max_pending":128,"max_pending_per_user":16,"max_calls":128,"max_hit_slots":1000}}
```

workers为1..16，max_pending为workers..4096，max_pending_per_user为1..4096（同时受全局容量限制），max_calls为1..100000，max_hit_slots为1..1000000，均拒绝布尔或非整数。预览返回execution_limits；进度返回execution_queue和execution_budget。Chat检索节点展开后显示调用/原始命中额度，区分排队中、检索中和预算已用尽。

这些参数是服务治理默认值，不是已验证的生产容量。真实W3身份及内网联测尚待平台配置；本地模拟并发通过不能代替真实多人账号和依赖容量验收。
